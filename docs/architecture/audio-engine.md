# Motor de audio y sonificación

## Motor de audio (frontend)

Web Audio API: reproducción, mezcla de capas, control de volumen, procesamiento en tiempo real.

## Motor de sonificación (backend, Python)

- Obtener datos científicos.
- Validar y normalizar.
- Seleccionar intervalos.
- Convertir valores en parámetros musicales.
- Generar configuración reproducible.
- Documentar reglas de mapeo.

## Mapeo científico-musical (ejemplos)

| Variable | Parámetro musical posible |
|---|---|
| Temperatura | Altura tonal |
| Velocidad | Ritmo |
| Intensidad | Volumen |
| Variación | Modulación |
| Densidad | Complejidad musical |
| Tiempo | Evolución |

Estas correspondencias son decisiones artísticas, no equivalencias científicas universales.
