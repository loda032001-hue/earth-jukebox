# Licencias

Pendiente de verificación detallada por fuente. Cada grabación y conjunto de datos debe incluir licencia documentada.

Fuentes de mapas:
- OpenStreetMap data © OpenStreetMap contributors (ODbL).
- Tiles de tile.openstreetmap.org sujetos a Tile Usage Policy.

Fuentes de audio: verificar licencias CC/PD por recurso.

Fuentes científicas: verificar términos de uso de cada API.
