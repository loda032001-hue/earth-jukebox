# Fuentes de datos científicos (candidatas a verificar)

## NASA POWER

- URL base: https://power.larc.nasa.gov/api
- Datos: meteorológicos y solares (temperatura, viento, precipitación, humedad, etc.).
- Autenticación: no requiere API key (verificar límites).
- Documentación: https://power.larc.nasa.gov/docs/services/api/
- Uso: adaptador inicial recomendado para Etapa 4.

## NOAA Climate Data Online (CDO)

- Requiere token gratuito.
- Datos climáticos históricos.
- Verificar límites y términos.

## Otras fuentes a investigar

- NOAA CO-OPS (mareas/corrientes).
- Instituciones oceanográficas (datos de temperatura oceánica).
- Repositorios abiertos (Zenodo, PANGAEA) para conjuntos de datos verificables.

## Regla

Nunca inventar endpoints ni datos. Verificar documentación oficial antes de integrar.
