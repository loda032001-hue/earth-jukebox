# Fuentes de audio (candidatas a verificar)

- **Freesound.org**: API v2, licencias Creative Commons. Requiere API key. https://freesound.org/docs/api/
- **Xeno-canto**: grabaciones de aves, licencias CC. Requiere API key. (Verificar acceso actual; puede estar protegido.)
- **Internet Archive**: grabaciones de dominio público/CC. Verificar licencias por item.
- **NASA Audio (space sounds)**: dominio público, pero no sonidos terrestres; útil como referencia.
- **NOAA Ocean Acoustics / PMEL**: datos acústicos oceánicos (verificar disponibilidad y licencias).
- **Wikimedia Commons**: audio con licencias CC; verificar por archivo.

Regla: no presentar sonidos sintéticos como grabaciones auténticas. Documentar autor, fuente, licencia y precisión geográfica.
